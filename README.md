# Meu Ônibus — Downloads

Aplicativo Android para passageiros de Tabatinga, Umarizeiras e Amanari, em Maranguape.

## Baixar e atualizar

Abra [a versão mais recente](https://github.com/Angelosxzz/MeuOnibus-Downloads/releases/latest) e baixe o arquivo APK na seção **Assets**. Instale sobre a versão anterior, sem desinstalar. Android 8 ou superior.

Todas as versões publicadas ficam na [aba Releases](https://github.com/Angelosxzz/MeuOnibus-Downloads/releases).

As previsões usam horários e itinerários cadastrados; não há rastreamento ao vivo dos ônibus.

Este repositório contém somente informações de download e APKs dos passageiros. O código do projeto e o app administrador são mantidos separadamente.
